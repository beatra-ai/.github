# .github

Default community health files for every [beatra-ai](https://github.com/beatra-ai) repository: security policy, support guide, and issue forms.

A repository that ships its own copy of one of these files uses that copy instead.

- [`SECURITY.md`](SECURITY.md) — private vulnerability reporting, scope, and package-manager update policy (no self-updater).
- [`SUPPORT.md`](SUPPORT.md) — where to get help with skills, credits, billing, and bug reports.
- [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) — bug report and skill request forms for [`beatra-ai/beatra-skills`](https://github.com/beatra-ai/beatra-skills/issues).
