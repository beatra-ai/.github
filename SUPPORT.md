# Getting help

| You need | Go to |
| --- | --- |
| How to install or use a skill | The skill's README, then [docs.beatra.ai](https://docs.beatra.ai) |
| Credits, billing, or your account | [console.beatra.ai](https://console.beatra.ai) or [support@beatra.ai](mailto:support@beatra.ai) |
| A skill behaves wrong | [Bug report](https://github.com/beatra-ai/beatra-skills/issues/new?template=bug-report.yml) |
| A skill you wish existed | [Skill request](https://github.com/beatra-ai/beatra-skills/issues/new?template=skill-request.yml) |
| A security problem | [SECURITY.md](SECURITY.md), never a public issue |

All skill feedback goes to [`beatra-ai/beatra-skills`](https://github.com/beatra-ai/beatra-skills/issues), including feedback on single-skill repositories. Those repositories are published automatically from that catalog and do not take issues or pull requests.

Account, billing, and payment questions contain personal details, so please email them instead of opening an issue.

## 获取帮助（中文）

- 安装和使用：先看 Skill 的 README，再看 [docs.beatra.ai](https://docs.beatra.ai)
- 积分、账单、账号：[console.beatra.ai](https://console.beatra.ai) 或发邮件到 [support@beatra.ai](mailto:support@beatra.ai)，涉及个人信息，请不要发公开 issue
- Skill 出错或想要新 Skill：统一在 [`beatra-ai/beatra-skills`](https://github.com/beatra-ai/beatra-skills/issues/new/choose) 提 issue
